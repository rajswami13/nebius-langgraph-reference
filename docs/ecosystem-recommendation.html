Listed everywhere, default nowhere: three partners to fix that

Bottom line

Most agent frameworks already list Token Factory, but none treats it as the default, and a listing doesn't mean the integration works. For the next two quarters, turn three listings into certified, default-quality integrations, and build the machine that keeps ten of them working.

Three partners, in priority order

Ranked by developer reach × tokens per developer × the gap between "listed" and "default."

  1. LangChain / LangGraph

    Q1 · weeks 1–8

    Largest agent framework. The partnership is already announced (Deep Agents), but the package underneath it is broken. That makes it the fastest path to revenue and the biggest risk if left alone.

    We deliverA fixed langchain-nebius that we own, in LangChain's standard integration tests; tuned Deep Agents profiles; correct Nebius pricing in LangSmith.
    Nebius offersA named FDE owner with a bug SLA, inference credits for Deep Agents users, co-marketing at every open-model launch, and capacity for LangChain's own evals.

  2. Vercel: AI SDK + AI Gateway

    Start Q1 · land Q2

    Reaches the TypeScript half of the agent market, and Gateway traffic is paid tokens that flow to us directly. Gateway lists only part of our catalog (5 models at last check, against 30 on Token Factory), and the AI SDK has no native Nebius provider.

    We deliverOur full agent-capable catalog on Gateway, day-0 listings for new open models, a native AI SDK provider, and agent templates that deploy on Vercel.
    Nebius offersWholesale pricing or a revenue share on Gateway traffic, committed rate limits, and early access to new models.

  3. An open-source coding agent: Cline first, OpenCode as the alternate

    Q2

    Coding agents use the most tokens per developer, and they rely heavily on tool calls, which is where we found server bugs. Integrations shipped in Q3, but we're not yet the recommended provider.

    We deliverCertified coding models (tool calls that pass the kit), a recommended Nebius preset in the agent, and latency tuning.
    Nebius offersCredits for the partner's users, fast-inference capacity for coding models, and a revenue share on referred tokens.

How this reaches ten partners. The four FDEs land the first three by hand. For partners 4–10 (OpenAI Agents SDK, PydanticAI, CrewAI, LlamaIndex, Mastra, n8n, OpenCode), each partner runs our conformance kit in its own CI, and FDE time is capped at roughly one week per partner. The OpenAI Agents SDK is cheap to add: Token Factory already answers the Responses API.

The trade-off

We go deep on three partners and put one of four FDEs on the platform instead of on a fourth partner. For two quarters, partners 4–10 get only self-serve support, and a competitor (Together, Fireworks, Groq) may win the default slot in a framework such as Mastra or n8n first. We accept that because a broken integration, like today's langchain-nebius, costs us more trust than a missing one.

One ask

Make the conformance kit a release gate, with an owner on the inference team.

No model ships on Token Factory until it passes the kit, and compatibility bugs the kit finds get a 2-week fix SLA. Two of the four issues above are server-side. FDEs can work around a server bug in one framework, but not in ten.
