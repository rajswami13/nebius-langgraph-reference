The trade-off

We choose depth over breadth: one of the four FDEs builds the platform instead of landing a fourth partner. Partners 4–10 get only limited enablement for two quarters, and a competitor may win the default slot in Mastra or n8n first. We accept that, because a broken integration costs more trust than a missing one.

One ask

A capability-based release gate, owned by the inference team.

Each model must pass the checks for the capabilities it advertises before launch, and models marketed for agents must also pass the full agent-ready suite. For a severity-1 compatibility bug, the inference team ships a mitigation within 48 hours and a permanent fix within 2 weeks. Exceptions need the inference lead's sign-off. Two of the four defects above are server-side. FDEs can work around a server bug in one framework, but not in ten.
